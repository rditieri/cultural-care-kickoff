# Cultural Care Kickoff Prompts

The phone page behind the QR code on the Cultural Care US Kickoff card, breakout sheet and slides (Oct 1, 2026).

**Live:** https://rditieri.github.io/cultural-care-kickoff/

All 13 prompts with copy buttons, how to start in Langdock, the data rule and the breakout on paper. Hidden from search engines.

## Updating

`index.html` is generated from `langdock-prompts.md` by `qr-page/gen.py` in the kickoff working folder. Regenerate, then replace `index.html` here. The link never changes, so the printed QR keeps working.
